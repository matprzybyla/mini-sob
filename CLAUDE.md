## Shadows of Brimstone
This is tabletop dungeon crawler game set in Dark Wild West setting insipored by Chtulhu and horros. 

## Core rules
- **Simplicity** - do not overenginner, prefer simpler solutions and approach
- **Minimal code changes** - if there is no need to


## Tech stack
- **Next.js frontend** - lightweight and fast frontend library
- **Supabase** - used for data persistence and campaign login or maybe something simpler is ok?
